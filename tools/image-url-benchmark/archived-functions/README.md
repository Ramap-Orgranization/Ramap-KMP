# 종료된 이미지 캐시 실험 소스

2026-10-12 기본 Storage 배치 발급 채택 후 운영 리소스 정리 과정에서 옮긴 소스다.
`supabase/functions/`와 배포 설정에서 제외했다. 하위 9개 파일은 이동 전후 SHA-256이 동일하다.
하위 README는 당시 사용법을 보존한 역사적 설명이며 현재 운영 배포 지시가 아니다.

- `image-signed-urls/`: Redis 캐시·권한 조회·잠금 구현과 모의 네트워크 테스트.
- `redis-connection-check/`: 연결 확인용 로컬 소스. 운영 v3와 로컬 소스의 동일성을 보증하지 않는다.

원본 측정 JSON과 성능 보고서는 `docs/performance/image-url-cache/`에 보존한다.
새 실험이 필요하면 별도 승인된 검증 환경을 준비한다. 운영 리소스를 자동 복구하거나 재배포하지 않는다.
