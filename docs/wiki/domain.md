# 도메인 용어와 관계

제품 정책을 읽을 때 같은 단어를 같은 의미로 사용하기 위한 문서입니다. 용어의 의미나 관계가 바뀌면 해당 정책도 함께 확인합니다.

## 매장과 개인화

| 개념 | 의미 | 구분할 것 |
| --- | --- | --- |
| 매장 | 위치·메뉴·영업시간과 리뷰·소식을 연결하는 장소 | 외부 지도 검색 후보가 곧 등록된 매장은 아닙니다. |
| 북마크 | 사용자가 나중에 찾으려고 저장한 매장 | 저장 여부와 매장 자체의 공개 여부는 별개입니다. |
| 개인 숨김 | 사용자가 자신의 탐색에서 제외한 매장 | 다른 사용자의 조회 권한이나 매장의 운영 상태를 바꾸지 않습니다. |
| 서비스 비공개 매장 | 서비스에서 공개 조회를 허용하지 않는 매장 | 개인 숨김과 다릅니다. 관련 공개 조회에도 이 경계가 적용됩니다. |
| 장소 검색 후보 | 외부 장소 정보와 등록 매장을 연결하기 위한 후보 | 이미 저장했거나 개인적으로 숨긴 매장은 가져오기 후보에서 제외합니다. |

## 계정·프로필·리뷰

프로필은 사용자의 공개 신원 정보와 콘텐츠 공개 설정을 담습니다. 비공개 프로필이라는 이유만으로 닉네임과 현재 프로필 사진까지 숨기지는 않습니다. 차단·정지·탈퇴에 따른 접근은 별도의 조건입니다.

리뷰는 작성자와 매장에 연결된 방문 기록입니다. 본문·사진, 작성자가 선택한 공개 여부, 게시·검수 상태는 서로 다른 의미를 가집니다. **공개 리뷰와 게시 가능한 리뷰를 같은 뜻으로 사용하지 않습니다.** 본인 목록과 다른 사람의 목록은 열람 범위가 다릅니다.

페이지는 목록을 나누어 조회하는 단위입니다. 현재 페이지에 보이는 행의 수를 작성자의 전체 리뷰 수로 해석하지 않습니다. 같은 매장에 남긴 반복 방문 리뷰는 서로 다른 기록이며, 본문을 수정하는 일과 새 방문을 추가하는 일도 구분합니다. 방문 회차는 작성 시 부여된 번호를 사용하며, 다른 리뷰의 삭제·공개 여부 변경으로 기존 기록의 번호를 다시 매기지 않습니다.

리뷰 목록과 가게 상세는 탐색 상태를 공유합니다. 내 리뷰에서 상세를 열고 변경 없이 닫으면 필터와 스크롤을 보존하고 목록을 다시 가져오지 않습니다. 성공한 리뷰 변경은 리뷰 화면과 상세 캐시가 함께 반영하며, 단순 화면 복귀는 사진 URL 재발급을 시작하지 않습니다. 관련 승인 결정은 [DEC-0006](decisions.md#dec-0006-리뷰-목록의-가게-카드와-상세-표시-통합)–[DEC-0008](decisions.md#dec-0008-리뷰-변경-기록으로-화면-동기화)입니다.

## 피드

피드는 공개된 사용자 리뷰를 모아보는 공간입니다. 작성자와 매장 정보를 함께 확인하고 최신순 또는 인기순으로 탐색합니다. 리뷰의 공개 범위와 차단·신고 규칙은 다른 리뷰 화면과 함께 적용합니다.

## 이벤트와 영업시간

- **이벤트:** 매장에 연결된 기간 있는 소식입니다. 이벤트 상세와 알림 설정은 같은 이벤트를 기준으로 합니다.
- **정규 영업시간:** 요일별로 반복되는 기본 일정입니다.
- **영업 변동:** 특정 날짜나 기간의 임시 휴무·조기 마감·운영 변동을 알리는 전체 기능입니다.
- **조기 마감:** 정상 영업 중 수량 소진 등의 이유로 정규 영업시간보다 일찍 마감한 실제 발생 공지입니다. 확인된 마감 시각 이후 해당 영업일의 영업을 종료합니다. 공지 유형과 현재 영업 상태는 구분하며, 마감 시각 전까지 하루 전체를 영업 종료로 보지 않습니다.
- **운영 변동:** 사전에 정해진 사유로 정규 종료 시각보다 일찍 마감하는 단축 영업 공지입니다. 예정 종료 전에는 정규 영업·브레이크타임을 유지합니다.
- **임시 휴무:** 특정 날짜나 기간에 영업하지 않는 공지입니다. 반복되는 정기휴무는 정규 영업시간에 속합니다.
- **휴무:** 해당 날짜에 영업하지 않는 상태입니다. 변경 일정이나 정규 시간보다 우선합니다.
- **수집된 영업 상태:** 외부 정보에서 관측한 상태와 확인 시점입니다. 사용자에게 공개하는 상태와 내부 수집 진단은 구분합니다.

매장과 공지의 적용 날짜는 별개의 기준입니다. 한 매장에 오늘 공지가 있어도 미래 날짜의 다른 공지가 없어지는 것은 아닙니다. 오늘 목록의 상세는 오늘 적용 공지를, 예정 목록의 상세는 그 매장의 유효한 예정 공지들을 보여줍니다. 원문에 포함된 날짜 표현과 실제 공지 적용 기간은 보존합니다. [DEC-0025](decisions.md#dec-0025-새소식의-매장별-목록과-검색저장-필터-복원)

실제 표시할 날짜의 영업시간은 [제품 정책의 영업 변경 규칙](product-policy.md#이벤트와-영업-변경)을 따릅니다.

## 알림과 첨부 자료

이벤트 알림 설정, 운영체제의 알림 권한, 기기의 푸시 식별자는 서로 다른 상태입니다. 하나가 존재한다고 나머지가 허용되었거나 실제 알림이 도착했다고 판단하지 않습니다.

프로필·리뷰 사진은 콘텐츠의 이미지이고, 제보 사진은 검토를 위한 증거입니다. 동일한 파일 저장소를 사용하더라도 공개·삭제 규칙을 공유하지 않습니다. 서명된 이미지 링크는 만료되는 접근 수단이며, 파일 소유권이나 영구 공개 주소가 아닙니다.
