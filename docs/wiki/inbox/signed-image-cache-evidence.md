# 이미지 링크 방식의 선택

## 질문과 처리

서버 공유 캐시가 기본 일괄 발급보다 운영 비용과 복잡성을 정당화하는지 검토했습니다. 사용자가 기본 배치와 기존 권한 검증 유지를 승인해 채택했습니다. [DEC-0003](../decisions.md#dec-0003-프로필리뷰-이미지-url-기본-배치-발급-채택)과 [현재 이미지 접근 경계](../backend.md#이미지-링크)에 연결합니다.

선택 이유는 당시 비교에서 추가 공유 캐시의 복잡성을 정당화할 이득을 확인하지 못했기 때문입니다. 상세 측정과 정리 이력은 로컬 변경 기록·성능 자료에서 관리합니다. 과거 캐시 구현을 현재 운영 구조로 해석하지 않습니다.

## 남은 한계

실제 경로 재사용률, 다른 화면·기기·동시 부하, Disk IO 개선을 일반화하지 않습니다. 향후 캐시를 재검토하려면 재사용률·권한 조회 비용·장애 시 동작의 근거가 필요합니다. 이 한계는 이미 승인한 기본 일괄 발급 선택을 미확정으로 되돌리는 뜻이 아닙니다.
