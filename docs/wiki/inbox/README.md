# 지식 후보함

아직 정하지 못한 정책·도메인 질문이나 재사용할 판단을 보관합니다. 후보는 승인된 정책이나 구현 지시가 아닙니다. [양식](../templates/knowledge-candidate.md)을 한 주제당 한 파일로 사용합니다.

질문, 확인한 근거, 미확인 범위와 다음 확인 방법을 적습니다. 작업 로그·읽힌 횟수·테스트 개수를 계속 누적하지 않습니다. 확정한 후보는 정책·도메인 문서와 결정 이유에 연결합니다. [유지보수 규칙](../maintenance.md#결정과-후보)

현재 미해결 후보는 없습니다. 처리한 질문은 아래와 같습니다.

- [개발 규칙과 구현 위치의 차이](source-alignment.md): 사용자 승인으로 소유 스킬을 정합화했습니다. [DEC-0002](../decisions.md#dec-0002-현재-구현을-기준으로-개발-규칙-정합성-확정)
- [이미지 링크 방식의 선택](signed-image-cache-evidence.md): 기본 일괄 발급을 채택했습니다. 다른 부하와 기기의 성능 일반화는 별도 근거가 필요합니다. [DEC-0003](../decisions.md#dec-0003-프로필리뷰-이미지-url-기본-배치-발급-채택)
