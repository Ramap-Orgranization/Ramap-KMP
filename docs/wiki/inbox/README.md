# 지식 후보함

아직 확정하지 않은 재사용 지식이나 규칙과 구현의 불일치를 보관합니다. 후보는 공식 정책이나 구현 지시가 아닙니다. [양식](../templates/knowledge-candidate.md)을 한 주제당 한 파일로 복사해 작성합니다.

작성 전 기존 위키·스킬·후보를 검색합니다. 확인한 근거, 미확인 범위, 다음 확인 방법을 적고 실제 판단에 사용한 작업만 이력에 남깁니다. 읽거나 검색된 횟수는 사용 이력이 아닙니다. 승격·기각은 [유지보수 정책](../maintenance.md)을 따릅니다.

현재 미해결 후보는 없습니다.

처리 이력: [개발 규칙과 구현 위치의 차이](source-alignment.md)는 현재 구현 기준으로 확정하여 [DEC-0002](../decisions.md#dec-0002-현재-구현을-기준으로-개발-규칙-정합성-확정)로 승격했습니다.
