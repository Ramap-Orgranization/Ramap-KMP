# 개발 규칙과 구현 위치의 차이

## 질문과 처리

초기 문서의 모듈 목록, 리소스 mapper 소유권, 도메인 analytics 의존성 설명이 실제 구조와 달랐습니다. 사용자가 당시 구현을 기준으로 정합화하도록 승인해 소유 스킬에 반영했습니다. 승인과 이유는 [DEC-0002](../decisions.md#dec-0002-현재-구현을-기준으로-개발-규칙-정합성-확정)에 보존합니다.

현재 파일 배치와 개발 규칙은 소유 스킬과 소스에서 확인합니다. 이 후보를 현재 클래스·모듈 목록으로 갱신하지 않습니다. 정책·도메인 위키와 구현 지침의 역할 구분은 [개발 참고](../engineering.md)를 따릅니다.
