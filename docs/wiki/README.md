# Ramap 정책·도메인 위키

Ramap은 라멘 매장을 발견하고 저장하며, 방문 리뷰와 이벤트·영업 소식을 나누는 앱입니다. 이 위키는 **무엇을 의미하고, 어떤 규칙을 지키며, 왜 그렇게 결정했는지**를 다음 작업에도 전달합니다.

## 필요한 지식부터 읽기

| 궁금한 것 | 문서 |
| --- | --- |
| 매장·리뷰·공개·숨김은 무엇을 뜻하는가 | [도메인 용어와 관계](domain.md) |
| 사용자가 할 수 있는 일과 지켜야 할 조건은 무엇인가 | [제품 정책](product-policy.md) |
| 각 기능이 해결하는 사용자 목적은 무엇인가 | [기능과 도메인](feature-map.md) |
| 로그인·검색·작성·화면 복귀는 어떻게 이어지는가 | [사용자 흐름](app-flows.md) |
| 누가 정보를 볼 수 있고 운영에서 어떤 경계를 지키는가 | [운영·보안 규칙](backend.md) |
| 과거 선택의 이유와 대안은 무엇인가 | [결정 기록](decisions.md) |
| 아직 정해지지 않은 질문은 무엇인가 | [지식 후보함](inbox/README.md) |
| 언제 무엇을 갱신하는가 | [유지보수 규칙](maintenance.md) |

구현 작업에는 [개발 참고](engineering.md)와 저장소의 `AGENTS.md`, 관련 프로젝트 스킬을 사용합니다. 위키에 클래스·함수 목록이나 코드 설명을 다시 만들지 않습니다.

## 지식의 상태

- **확정 정책:** 사용자 승인과 결정 기록이 있는 규칙입니다. 바꾸려면 그 정책의 승인 범위를 확인합니다.
- **도메인 지식:** 기존 문서와 구현에서 확인한 개념·관계·동작입니다. 새 요구사항을 승인한 것으로 해석하지 않습니다.
- **미확정 질문:** 후보함에 두고 확인한 사실과 아직 모르는 점을 나눕니다.

정책의 현재 내용은 제품 정책과 운영·보안 규칙에서, 결정한 이유는 결정 기록에서 읽습니다. 문서와 구현이 다르면 어느 쪽이 맞는지 임의로 결정하지 않고 불일치를 확인합니다.

위키의 이 방향은 [DEC-0017](decisions.md#dec-0017-정책도메인-중심-위키와-의미-변경-갱신)로 확정했습니다. 이전 결정과 이미 승인된 제품 정책은 유지합니다.
