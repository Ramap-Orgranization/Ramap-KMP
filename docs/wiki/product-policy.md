# 제품 정책

이 문서는 사용자가 할 수 있는 일, 경계 조건과 예외를 설명합니다. 명시적으로 승인된 변경은 결정 ID를 연결하고, 나머지 항목은 이전 문서에서 확인한 기존 도메인 규칙으로 유지합니다. 구현·배포 버전의 목록은 이 문서에 넣지 않습니다.

## 지도와 검색

- 하단의 주요 화면은 한국·랭킹·새소식·마이입니다.
- 일본 지도는 한국 지도 안의 전환 버튼으로 열며, 일본 화면의 복귀 버튼이나 뒤로 가기로 한국 지도에 돌아옵니다. 각 지도의 카메라를 보존합니다.
- 일본 지도의 초기 위치는 도쿄역입니다. 키가 없는 환경에서는 준비 문구를 보여줍니다. 일본 매장 데이터 연결은 후속 범위입니다. 이 결정은 승인된 제품 정책을 기록하며, 그 자체로 각 클라이언트의 배포 완료를 뜻하지 않습니다. [DEC-0013](decisions.md#dec-0013-일본-google-지도-화면-추가)
- 지도 검색은 정규화한 입력 2~15자를 사용하고 결과는 최대 50개입니다. 새 검색은 이전 검색을 교체합니다.
- 검색 호출 제한은 사용자에게 제한 이유와 재시도 안내로 전달합니다. 다른 요청 실패와 같은 의미로 처리하지 않습니다. 운영 한도의 구체적인 수치는 서버 설정에서 관리합니다.

## 리뷰 작성과 공개

내 리뷰와 다른 사람 리뷰 목록은 공통 가게 리뷰 카드를 사용합니다. 내 리뷰에서 카드를 선택하면 현재 목록 위에 가게 상세를 표시해 필터와 스크롤 상태를 유지합니다. [DEC-0006](decisions.md#dec-0006-리뷰-목록의-가게-카드와-상세-표시-통합)

상세를 변경 없이 닫으면 내 리뷰 목록을 다시 조회하지 않습니다. 이 원칙은 상세 닫기에서 시작해 작성·수정·삭제 후 복귀에도 적용하는 변경 기록 방식으로 확장했습니다. [DEC-0007](decisions.md#dec-0007-내-리뷰-상세-닫기에서-목록-재조회-제외), [DEC-0008](decisions.md#dec-0008-리뷰-변경-기록으로-화면-동기화)

성공한 리뷰 작성·수정·삭제는 변경 기록을 통해 관련 화면에 반영합니다. 화면 복귀만으로 리뷰나 사진을 다시 불러오지 않습니다. 세션 전환, 접근 변경, 기록 공백처럼 상태를 복구할 이유가 있을 때 필요한 조회를 수행합니다. [DEC-0008](decisions.md#dec-0008-리뷰-변경-기록으로-화면-동기화)

- 본문은 앞뒤 공백을 제거한 뒤 Unicode code point 기준 5~30자이며 비속어를 검사합니다. 사진은 최대 3개입니다.
- 비공개 프로필에서 공개 리뷰를 제출하면 프로필을 비공개로 유지할지 공개로 바꿀지 확인합니다.
- 저장 실패 시 작성 중인 초안을 유지합니다.
- 공개 여부와 게시·검수 상태를 구분합니다. 다른 사용자의 목록에 작성자에게만 허용되는 비공개 결과를 섞지 않습니다.

## 프로필과 다른 사용자 접근

- 공개·비공개·차단·이용 불가 상태를 구분해 처리합니다.
- 비공개 계정에서도 닉네임과 현재 프로필 사진은 공개합니다. 리뷰·저장 목록의 공개 범위와 차단·정지·탈퇴 조건은 별도로 유지합니다. [DEC-0015](decisions.md#dec-0015-비공개-계정의-닉네임프로필-사진-공개-확정)
- 인스타그램 아이디 입력 기능은 제공하지 않습니다.
- 자기소개 등 사용자 입력은 앱과 서버에서 검증합니다. 잘못된 자기소개를 서버 오류로 취급하지 않고 입력 오류로 반환합니다.

## 제보 사진

사진에는 개인정보나 검토 중인 자료가 포함될 수 있으므로 공개하지 않습니다. 로그인한 제보자와 별도 등록한 관리자만 열람할 수 있습니다. [DEC-0016](decisions.md#dec-0016-제보-사진의-제보자관리자-열람-제한)

| 행동 | 조건 |
| --- | --- |
| 사진 업로드·첨부 제출 | 로그인과 본인 소유권이 필요합니다. |
| 사진 열람·목록 조회·새 링크 발급 | 제보자 본인 또는 등록 관리자만 허용합니다. |
| 제보자가 사진 삭제 | 아직 제보에 연결되지 않은 본인 사진만 허용합니다. |
| 제출된 사진 삭제 | 관리자만 정리합니다. |
| 기존 소유자 불명 사진 열람 | 제보자를 추측해 지정하지 않고 관리자만 허용합니다. |
| 기존 사진 덮어쓰기 | 허용하지 않습니다. |

URL만 보내는 익명 제보는 유지합니다. 발급된 서명 링크는 만료 전 소지자가 사용할 수 있으며 이미 내려받은 파일까지 회수하는 정책은 아닙니다.

## 저장 목록과 랭킹

가져오기에서는 이미 저장했거나 개인적으로 숨긴 매장을 후보에서 제외하고 사용자가 선택한 나머지를 저장합니다.

랭킹은 페이지 사이의 중복을 제거하고 같은 순위에서 다음 순위를 건너뛰지 않는 dense rank를 유지합니다. 북마크 표시 변화로 이미 받은 랭킹 순서를 재정렬하지 않습니다.

## 이벤트와 영업 변경

- 이벤트 상세의 결과 없음과 조회 실패를 구분합니다. 조회 실패에는 재시도할 수 있는 흐름을 제공합니다.
- 일반 이벤트는 선택한 시작일과 종료일을 유지합니다. 신메뉴는 7일 기간, 리뉴얼은 종료일 없음이라는 기존 규칙을 유지합니다.
- ‘영업 변동’은 전체 기능명이며 등록할 공지 유형은 **조기 마감·임시 휴무** 두 가지입니다. 일반 영업시간 변경과 오픈 지연은 공지 유형으로 제공하지 않습니다. [DEC-0018](decisions.md#dec-0018-영업-변동-유형과-조기-마감-적용-시각)
- 공지는 선택한 시작일부터 종료일까지 적용하며 월을 넘길 수 있습니다. 날짜 역전·존재하지 않는 날짜와 같은 공지의 중복 등록을 거절합니다. 월간 달력에서는 명시된 휴무 날짜만 개별 임시 휴무로 등록하고, 언급하지 않은 날짜는 휴무로 처리하지 않습니다.
- 임시 휴무는 해당 날짜의 정규 영업시간보다 우선합니다. 조기 마감은 정확한 마감 시각을 확인한 뒤 등록하며, 그 시각부터 매장 상세·검색 결과 등에서 **‘영업 종료’**로 표시합니다. 마감 전에는 정규 영업 및 브레이크타임을 따르되 표시할 종료 시각은 조기 마감 시각을 반영합니다.
- 정확한 시각이 없는 ‘점심만 영업’ 등의 문구만으로 조기 마감 시각을 자동 추정하지 않습니다. 확인되지 않은 기존 조기 마감 공지는 공개하지 않고 원본을 보존합니다.
- 매장 상세에서는 별도의 `조기 마감 >` 링크를 표시하지 않습니다. 영업 변동 공지 카드에도 마감 시각을 별도 행으로 표시하지 않으며, 시각은 영업 상태 판단에 사용합니다.

## 이벤트 알림

모든 시간은 한국 시각(KST)을 기준으로 합니다.

| 설정 시점 | 선택할 수 있는 알림 |
| --- | --- |
| 이벤트 전날 21시 이전 | 전날·당일 |
| 전날 21시부터 당일 09시 전 | 당일만 |
| 당일 09시부터 | 설정 창 종료 |

이 표는 설정 가능한 시간 창입니다. 실제 발송 성공이나 기기 수신을 보장하는 표가 아닙니다. 운영체제 권한과 푸시 등록도 별도로 확인합니다.
