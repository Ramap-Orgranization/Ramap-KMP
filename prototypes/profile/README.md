# Ramap 프로필 HTML 프로토타입

`index.html`을 브라우저로 열거나 다음 명령으로 실행합니다. 외부 라이브러리·네트워크 이미지 없이 동작합니다.

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory prototypes/profile
```

접속 주소: http://127.0.0.1:8767

- 기존 카카오 로그인 계정을 가정한 샘플입니다. 실제 계정·서버·앱 코드는 변경하지 않습니다.
- 처음 열면 라멘 관련 랜덤 닉네임을 부여하고 브라우저에 보관합니다. 새로고침으로 닉네임이 바뀌지 않습니다.
- 설정 → 내 프로필 → 수정, 닉네임 직접 입력, 사진 선택·기본 이미지 복원, 저장·취소를 체험합니다.
- 사진은 가운데를 정사각형으로 잘라 512px로 저장합니다. JPG/PNG/WebP, 최대 5MB입니다.
- 닉네임은 한글·영문·숫자·밑줄 2~10글자를 적용합니다. 중복 여부는 서버 연결 전이므로 검사하지 않습니다.
- **첫 방문 체험**은 확인 후 이 프로토타입의 샘플 프로필만 초기화합니다.

Playwright가 설치된 환경에서 회귀 확인:

```sh
node prototypes/profile/check.cjs
```

필요하면 `CHROME_PATH`로 로컬 Chromium 실행 파일, `PROFILE_URL`로 미리보기 주소를 지정합니다.
